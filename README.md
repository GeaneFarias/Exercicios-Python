# 🐍 Exercícios em Python

Este repositório reúne diversos exercícios desenvolvidos em Python, com o objetivo de treinar lógica de programação, manipulação de dados, estruturas de repetição, condicionais, funções e muito mais.

🔧 **Voltado para aprendizado, revisão e desenvolvimento de habilidades como Dev Back-end.**

## 📚 Tecnologias e Conceitos Aplicados
Python 3.x

Lógica de Programação

Funções e Módulos

Estruturas Condicionais e de Repetição

Manipulação de Strings e Arquivos

Bibliotecas: os, random, datetime, cv2 (OpenCV)

## 🤓 Objetivo
Este repositório serve como uma coleção de práticas para fixar o aprendizado de Python e também como referência para quem está começando.


## 📁 Estrutura do Repositório

Os exercícios estão organizados em arquivos separados. Cada arquivo representa um desafio ou tema diferente. Exemplos:

- `calculadora_simples.py` – Operações básicas (soma, subtração, etc)
- `media_escolar.py` – Cálculo de média com condicionais
- `verificador_palindromo.py` – Teste se uma palavra é um palíndromo
- `jokenpo.py` – Jogo de pedra, papel e tesoura
- `organizadorde_arquivos.py` – Script que organiza arquivos em pastas (automação)
- `reconhecimento_facial.py` – Projeto com OpenCV para detectar rostos (aprendizado de máquina)

> Você pode executar qualquer um dos scripts individualmente para testar!
